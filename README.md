# ESP32 Rust Project (`esp32rust`)

Rust project configured for the **ESP32** microcontroller (Xtensa dual-core) using the `std` library approach with `esp-idf-svc`.

## Prerequisites

To build and flash firmware for ESP32 (Xtensa), install `espup` and the ESP-RS toolchain:

1. **Install `cargo-espflash` and `ldproxy`:**
   ```bash
   cargo install cargo-espflash ldproxy
   ```

2. **Install the Xtensa toolchain with `espup`:**
   ```bash
   cargo install espup
   espup install
   ```

3. **Export environment variables generated by `espup`:**
   ```bash
   . $HOME/export-esp.sh
   ```

## Build and Run

- **Build the project:**
  ```bash
  cargo build
  ```

- **Flash to the board and monitor serial logs:**
  ```bash
  cargo run
  # or
  cargo espflash flash --monitor
  ```

## Project Structure

- `Cargo.toml`: Rust dependencies (`esp-idf-svc`, `log`, `embuild`, `anyhow`).
- `.cargo/config.toml`: Target configuration (`xtensa-esp32-espidf`), linker (`ldproxy`), and runner (`espflash`).
- `rust-toolchain.toml`: Specifies the `esp` toolchain channel.
- `build.rs`: Build script integrated with `embuild`.
- `sdkconfig.defaults`: Default ESP-IDF settings (e.g. stack size tuned for Rust).
- `src/main.rs`: Application entry point (Wi-Fi initialization and connection loop).
